File breakdown

    - This file contains the main game loop and the logic that runs the Mastermind game. It is the entry point of the application.
- utilities.rb
    - This file contains utility functions that assist with string formatting, game logic and providing hints.
- string_extensions.rb
    - This file extends the Ruby String class to add color methods for easy terminal output customization.
